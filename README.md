1. Connect STLINK with STM32 Bluepill
2. Connect FTDI with UART2 port
3. Make sure to connect 3.3V and Ground both with it
4. Connect RX to TX and TX to RX
5. UART2 on Bluepill is : PA2_TX, PA3_RX
